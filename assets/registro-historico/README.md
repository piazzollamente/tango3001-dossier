# Registro histórico de imágenes de Piazzollamente

Esta carpeta reúne las fotografías que formarán la sección visual de trayectoria del sitio.

## Orden de los archivos

Nombrar cada imagen comenzando por la fecha para conservar el orden cronológico:

```text
AAAA-MM-DD-ciudad-hito-01.webp
AAAA-MM-DD-ciudad-hito-02.webp
```

Si solo se conoce el año:

```text
AAAA-ciudad-hito-01.webp
```

Ejemplos:

```text
2023-mendoza-san-vicente-tango-01.webp
2024-rancagua-teatro-regional-01.webp
2025-coquimbo-gira-territorial-01.webp
2026-valparaiso-valparatango-01.webp
```

## Criterios

- Usar minúsculas, números y guiones; evitar espacios, tildes y caracteres especiales.
- Mantener una numeración sucesiva cuando un mismo hito tenga varias fotografías.
- Conservar aparte los datos de autoría, lugar, fecha y evento para incorporarlos a los créditos del collage.
- Preparar las copias para web en formato WebP, sin reemplazar ni eliminar los originales de alta resolución.
